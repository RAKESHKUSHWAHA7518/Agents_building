# Sample Documents

Put your PDF files here to use with lesson10-pdf-rag.js

## How to use

1. Copy any PDF file into this folder
2. Rename it to `sample.pdf` (or update `PDF_PATH` in lesson10-pdf-rag.js)
3. Run: `node lesson10-pdf-rag.js`

## Good PDFs to try

- Your own resume
- A textbook chapter
- A company annual report
- Any Wikipedia article saved as PDF
- A product manual
